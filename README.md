# 📈 Stock Data Service

**Stock Data Service** — это автономный сервис для сбора, обработки и анализа биржевых данных с MOEX API.

Проект представляет собой модульную ETL-систему (Extract – Transform – Load) для автоматического сбора, обработки и хранения биржевых котировок и торговых показателей.

Система автоматически извлекает данные с Московской биржи (MOEX), очищает и нормализует их, а затем сохраняет в базу данных PostgreSQL. Пользователи могут получать доступ к данным через веб-интерфейс и формировать аналитические отчеты.

## 🎯 Основные возможности

* 🔍 **Автоматический сбор данных с MOEX API** - асинхронное получение биржевых котировок (цены, объемы, изменения) для акций рынка TQBR

* 🧹 **Очистка и нормализация данных** - автоматическая обработка сырых данных: преобразование типов, удаление некорректных записей, перерасчет процентных изменений

* 📊 **Аналитическая обработка** - расчет статистических показателей по каждому финансовому инструменту за выбранный период

* 📥 **Экспорт данных в CSV и XLSX** - выгрузка как детализированных котировок, так и аналитических сводок

* 🔐 **Личный кабинет пользователя** - авторизация, персональный профиль 

* ⏰ **Планировщик задач** - автоматический сбор данных в рабочие часы биржи (10:00-19:00) с интервалом 10 минут

## 📊 Аналитический модуль

Модуль выполняет статистическую обработку исторических биржевых данных и формирует агрегированные показатели по каждому финансовому инструменту за выбранный период.

После загрузки и нормализации котировок данные передаются в аналитический слой, где выполняется группировка по тикерам и их наименованиям с расчетом основных статистических характеристик.

Модуль рассчитывает:

- **Количество наблюдений** по тикеру
- **Среднюю цену** актива
- **Медианную цену** 
- **Минимальное и максимальное** значение цены
- **Среднее изменение** цены
- **Среднее процентное** изменение
- **Суммарный торговый объем**
- **Суммарную стоимость торгов**

Полученные результаты используются для формирования аналитических XLSX-отчетов и позволяют проводить первичный анализ динамики и торговой активности выбранных инструментов.

### Структура данных

| Поле           | Описание                                                     |
| -------------- | ------------------------------------------------------------ |
| id             | Уникальный идентификатор записи котировки                    |
| update_time    | Время последнего обновления котировки                        |
| ticker         | Тикер ценной бумаги                                          |
| name           | Полное название ценной бумаги                                |
| last_price     | Последняя цена на момент обновления                          |
| prev_price     | Цена закрытия предыдущей торговой сессии                     |
| change         | Изменение цены относительно предыдущего закрытия             |
| change_percent | Процентное изменение цены относительно предыдущего закрытия  |
| open           | Цена открытия текущей торговой сессии                        |
| high           | Максимальная цена за текущую торговую сессию                 |
| low            | Минимальная цена за текущую торговую сессию                  |
| volume         | Объём торгов в штуках (количество купленных/проданных лотов) |
| value          | Общая стоимость совершённых сделок                           |
| lot_size       | Размер лота                                                  |

## 🚀 Быстрый старт

1. Клонирование репозитория:

```bash
git clone https://github.com/fetgrigory/Stock-Data-Service.git
```

2. Подключение к базе данных на PostgreSQL

Для работы с базой данных требуется указать параметры подключения в файле `.env`:

* **HOST**: Адрес хоста базы данных.
* **DBNAME**: Имя базы данных.
* **USER**: Имя пользователя для доступа к базе данных.
* **PASSWORD**: Пароль к базе данных.
* **PORT**: Порт для подключения (например, 5432 по умолчанию для PostgreSQL).

### Пример заполнения:

```plaintext
HOST="localhost"
DBNAME="example_db"
USER="admin_user"
PASSWORD="strongpassword"
PORT="5432"
```

3. Создайте виртуальное окружение для изоляции зависимостей проекта.

Используйте команду:

```bash
uv venv
```

4. Активируйте виртуальное окружение:

* На Windows:

```bash
.venv\Scripts\activate
```

* На macOS и Linux:

```bash
source .venv/bin/activate
```

5. Установка зависимостей:

```bash
uv sync
```

6. Сборка образа в Docker:

```bash
docker-compose up -d --build
```

7. Запуск контейнера:

```bash
docker-compose up
```

8. Создание миграций (только при изменении моделей):

```bash
docker-compose exec stock-service uv run alembic revision --autogenerate -m "init schema"
```

9. Применить миграции:

```bash
docker-compose exec stock-service uv run alembic upgrade head
```

* Swagger UI доступен по адресу http://127.0.0.1:8000/docs
