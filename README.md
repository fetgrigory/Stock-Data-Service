# 📈 Stock Data Service

**Stock Data Service** — это автономный сервис для сбора, обработки и доставки биржевых данных с MOEX API.

Проект представляет собой модульную ETL-систему (Extract – Transform – Load) для сбора, обработки и хранения биржевых котировок и торговых показателей.

Система автоматически извлекает данные с торговых площадок, очищает и нормализует их, а затем сохраняет в базу данных PostgreSQL.

Для взаимодействия с данными реализован REST API на FastAPI, позволяющий управлять пользователями.

Система включает в себя:

* 🔍 **Асинхронный сервис получения рыночных данных с MOEX API** (цены, объемы, изменения)

* 📦 **Очистка и нормализация финансовых данных перед сохранением** в структурированном виде

* 📊 **Формирование аналитических XLSX-отчётов** для выбранного периода система рассчитывает агрегированные показатели по тикерам и формирует готовый Excel-отчёт.

* 📥 **Экспорт детализированных нормализованных биржевых данных в CSV** данные выгружаются без аналитической агрегации и могут использоваться для самостоятельного анализа, обработки и построения моделей.

* 🔑 **Защищённый веб-интерфейс с регистрацией, авторизацией и управлением профилем пользователя**

## 📊 Аналитический модуль

Модуль выполняет статистическую обработку исторических биржевых данных и формирует агрегированные показатели по каждому финансовому инструменту.

После загрузки и нормализации котировок данные передаются в аналитический слой, где выполняется группировка по тикерам и их наименованиям с расчётом основных статистических характеристик за выбранный период.

Модуль рассчитывает:

- количество наблюдений по тикеру;
- среднюю цену актива;
- медианную цену;
- минимальное и максимальное значение цены;
- среднее изменение цены;
- среднее процентное изменение;
- суммарный торговый объём;
- суммарную стоимость торгов.

Полученные результаты используются для формирования аналитических XLSX-отчётов и позволяют проводить первичный анализ динамики и торговой активности выбранных инструментов.

### Структура данных

| Поле           | Описание                                                     |
| -------------- | ------------------------------------------------------------ |
| id             | Уникальный идентификатор записи котировки                    |
| update_time    | Время последнего обновления котировки                        |
| ticker         | Тикер ценной бумаги                                          |
| name           | Полное название ценной бумаги                                |
| last_price     | Последняя цена на момент обновления                          |
| prev_price     | Цена закрытия предыдущей торговой сессии                     |
| change         | Изменение цены относительно предыдущего закрытия             |
| change_percent | Процентное изменение цены относительно предыдущего закрытия  |
| open           | Цена открытия текущей торговой сессии                        |
| high           | Максимальная цена за текущую торговую сессию                 |
| low            | Минимальная цена за текущую торговую сессию                  |
| volume         | Объём торгов в штуках (количество купленных/проданных лотов) |
| value          | Общая стоимость совершённых сделок                           |
| lot_size       | Размер лота                                                  |

## 🚀 Быстрый старт

1. Клонирование репозитория:

```bash
git clone https://github.com/fetgrigory/Stock-Data-Service.git
```

2. Подключение к базе данных на PostgreSQL

Для работы с базой данных требуется указать параметры подключения в файле `.env`:

* **HOST**: Адрес хоста базы данных.
* **DBNAME**: Имя базы данных.
* **USER**: Имя пользователя для доступа к базе данных.
* **PASSWORD**: Пароль к базе данных.
* **PORT**: Порт для подключения (например, 5432 по умолчанию для PostgreSQL).

### Пример заполнения:

```plaintext
HOST="localhost"
DBNAME="example_db"
USER="admin_user"
PASSWORD="strongpassword"
PORT="5432"
```

3. Создайте виртуальное окружение для изоляции зависимостей проекта.

Используйте команду:

```bash
uv venv
```

4. Активируйте виртуальное окружение:

* На Windows:

```bash
.venv\Scripts\activate
```

* На macOS и Linux:

```bash
source .venv/bin/activate
```

5. Установка зависимостей:

```bash
uv sync
```

6. Сборка образа в Docker:

```bash
docker-compose up -d --build
```

7. Запуск контейнера:

```bash
docker-compose up
```

8. Создание миграций (только при изменении моделей):

```bash
docker-compose exec stock-service uv run alembic revision --autogenerate -m "init schema"
```

9. Применить миграции:

```bash
docker-compose exec stock-service uv run alembic upgrade head
```
